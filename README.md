# BetterRadian - Pre-Alpha
###### Version 1.0 (17.09.2026).

## Why BetterRadian (BTRadian) Exists

<p>When People joined the Radian Platform on September 16, 2026, there wasn't really anything to do. The interface was basic and too bright, there was almost no functionality besides friending people, joining maps, browsing, and there was no native dark mode or custom control at the time, this is what led to the creation of <a href="https://klingri.github.io/BetterRadian/">BetterRadian</a> the very next day, people wanted dark mode badly because they don't like looking at bright lights for hour's.</p>

<strong>BetterRadian is what Radian should have been:</strong>

<ul>
    <li>User <i>Control</i> and User <i>Freedom.</i></li>
    <li>More focus on <i>Customization.</i></li>
    <li>
    Plus everything users have been asking for but never got (<i>BetterRadian</i> doesn't have everything just yet.)</li>
  </ul>

## Installation

<a href="https://github.com/Klingri/BetterRadian/blob/stable/.github/INSTALLATION.MD">full Installation guide.</a>

### Step-by-Step:
1. **Download:** Go to the [Releases](https://github.com/Klingri/BetterRadian/releases) page and download the latest `Source code (zip)`.
2. **Extract:** Unzip the folder to a permanent location on your PC.
3. **Open Extensions Page:**
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Firefox: `about:addons`
   - Brave: `brave://extensions/`
   - Vivaldi: `vivaldi://extensions`
   - Opera/OperaGX: `opera://extensions`
   - Arc: `arc://extensions`
   - Helium: `helium://extensions`
   - Yandex: `browser://extensions`
4. **Developer Mode:** Toggle the **Developer mode** switch in the top right.
5. **Load Unpacked:** Click **"Load unpacked"** and select the folder you just extracted.

## Known Issues & Stability (so far)
<div align="center">
<p>View the list of Issues (so far) <a href="https://github.com/Klingri/BetterRadian/blob/stable/.github/ISSUES.md">here.</a></p>
</div>

<ul>
    <li><strong>Performance:</strong> Experimental updates may cause performance instability and looses on less capable hardware.</li>
    <li><strong>UI Issues & UI Glitches:</strong> Some elements may display incorrectly.</li>
    <li><strong>No native Auto-Updater:</strong> Manual updating, the same way you first downloaded BetterRadian</li>
    <li><strong>Compatibility:</strong> BetterRadian might not work with Firefox, other radian extensions or older versions of BetterRadian</li>
    <li><strong>Themes:</strong> BetterRadian looks best in dark mode because it was built for it, and I cannot guarantee the look of light mode or other themes.</li>
